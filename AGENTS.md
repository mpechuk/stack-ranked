# Repository Agent Instructions

These instructions apply to the entire repository.

Before inspecting, planning, editing, testing, or otherwise working in this
repository, read both of the following files in full:

1. [`CLAUDE.md`](./CLAUDE.md) — mandatory repository-specific architecture,
   invariants, maintenance rules, verification requirements, and Git workflow.
2. [`README.md`](./README.md) — mandatory product overview, supported workflows,
   generated artifacts, and user-facing behavior.

Treat the guidance in both files as active instructions for every task, not as
optional background material. Re-read the relevant sections before changing
game logic, cards, rules, visuals, generated PDFs, networking, deployment, or
release behavior, and keep all duplicated sources and artifacts synchronized as
directed by `CLAUDE.md`.

If repository guidance conflicts, follow the more specific instruction for the
files being changed. Instructions supplied by the system, developer, or current
user take precedence over repository documentation.
